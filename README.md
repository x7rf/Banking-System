# Banking System

Java Swing desktop project using MVC, Observer, and an immutable account identifier. This Maven version preserves the source from the existing VS Code project, including the four accounts and their current balances.

## Requirements
JDK 25 or newer and Apache Maven 3.9 or newer. The first Maven build needs internet access to download plugins and the test dependency.

## Layout
```text
banking-system/
├── pom.xml
├── .gitignore
├── README.md
├── src/
│   ├── main/
│   │   ├── java/com/example/bankingsystem/
│   │   │   ├── AccountId.java
│   │   │   ├── BankApp.java
│   │   │   ├── BankController.java
│   │   │   ├── BankModel.java
│   │   │   └── BankView.java
│   │   └── resources/
│   └── test/
│       ├── java/com/example/bankingsystem/
│       │   └── BankModelTest.java
│       └── resources/
└── target/  (generated by Maven, ignored by Git)
```

The resource directories contain .gitkeep files so Git preserves these currently empty directories. Tests are separate from application code and contain no screenshot helpers.

## Run in VS Code
Open the folder containing pom.xml. With Microsoft's Extension Pack for Java installed, open BankApp.java and select Run above main().

Or use the terminal in the project root:
```sh
mvn clean test
mvn compile exec:exec
```

The full main class name is com.example.bankingsystem.BankApp.

## Build
```sh
mvn clean package
java -cp target/classes com.example.bankingsystem.BankApp
```

## Replace the old layout in an existing Git repository
Keep your existing .git directory. Replace the old src directory with this src directory (do not leave the old src/*.java files alongside it), and copy pom.xml, .gitignore and README.md into the project root. Then run the Maven checks above before committing:
```sh
git add .
git commit -m "Convert banking system to standard Maven layout"
git push
```

No PDF, screenshots, compiled classes, or Git history are included in this archive. Data is held in memory and resets at restart.
